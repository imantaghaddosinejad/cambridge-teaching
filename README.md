# PhD Computational Methods (University of Cambridge)

Teaching notes and MATLAB problem-set solutions for the first-year PhD Computational Methods course (PHD21), University of Cambridge.

- **Course lecturer:** Dr. Hanbaek Lee ([website](https://sites.google.com/view/hanbaeklee/home))
- **Teaching assistant:** Iman Taghaddosinejad. I wrote the solutions and notes in this repository.

## Contents

### 2026–27 (`PHD21_2026-27/`)

| Folder | Topic |
|---|---|
| `PS1/` | Problem Set 1: labour supply, general equilibrium, inequality moments |
| `PS3/` | Problem Set 3: incomplete-markets steady state, capital supply/demand, wealth distribution, borrowing limits; note on supermartingale theory |

Each problem set follows the same layout:

- `maincodes/`: entry-point scripts (run `main.m`)
- `functions/`: helper functions (Tauchen discretisation, interpolation, simulation, etc.)
- `figures/`: output figures
- `notes/`: supporting notes (where applicable)
