# PhD Computational Methods (University of Cambridge)

Teaching notes and MATLAB problem-set solutions for the first-year PhD Computational Methods course (PHD21), University of Cambridge.

- **Course lecturer:** Dr. [Hanbaek Lee](https://sites.google.com/view/hanbaeklee/home)
- **Teaching assistant:** Iman Taghaddosinejad

## Contents

### 2026–27 (`PHD21_2026-27/`)

| Folder | Topic |
|---|---|
| `PS1/` | Problem Set 1: labour supply, general equilibrium, inequality moments |
| `PS3/` | Problem Set 3: incomplete-markets steady state, capital supply/demand, wealth distribution, borrowing limits; note on supermartingale theory |
| `PS4/` | Problem Set 4: Aiyagari (1994) transitional competitive equilibrium after a permanent TFP jump; general vs partial equilibrium convergence, Gini along the transition path, one-period and decaying (MIT) TFP shocks; notes on measure-theoretic foundations of the TCE |
| `PS5/` | Problem Set 5: representative-agent RBC with endogenous labour and wealth adjustment costs; transitional equilibria for permanent and decaying TFP shocks; global nonlinear solution with aggregate TFP uncertainty via the repeated transition method |

Each problem set follows the same layout:

- `maincodes/`: entry-point scripts (run `main.m`)
- `functions/`: helper functions (Tauchen discretisation, interpolation, simulation, etc.)
- `figures/`: output figures
- `notes/`: supporting notes (where applicable)
